# AI Animation & Video Editor

An intelligent, full-stack Next.js application that uses Google Gemini to generate dynamic, programmatic animations (via Remotion TSX) and compiles them locally into MP4 videos. 

*Note: This tool specializes in programmatic motion graphics, UI animations, and logo reveals. Generative AI for natural, live-action video is planned for the roadmap.*

## ✨ Features

- **Text-to-Animation Code Generation:** Describe the motion graphics or UI animation you want, and the AI writes production-ready Remotion TSX code.
- **AI Prompt Enhancement:** Includes a built-in expert prompt engineer. Transform simple ideas into highly descriptive design specifications before generating code.
- **Dynamic Skill Injection:** Uses a modular `skills/` directory (e.g., `thesvg`, `remotion-editor`) that dynamically injects documentation and live databases (like the 6,000+ SVG icon registry) directly into Gemini's context at runtime.
- **Local Video Rendering Sandbox:** Safely compiles TSX code into MP4 videos using a completely isolated local Node.js process with `@remotion/bundler`.
- **Live Code Editor:** Includes an embedded Monaco editor so you can preview, tweak, and iterate on the generated TSX code before rendering.
- **Dynamic Model Selection:** Automatically syncs with the Google Gemini API to offer the latest production-ready models (like Gemini 1.5 Pro/Flash).

## 🚀 Setup & Run

1. **Install dependencies:**  
   Running install at the root automatically installs the Next.js dependencies and triggers a `postinstall` script to install the isolated Remotion renderer dependencies.
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Open the App:**  
   Open [http://localhost:3000](http://localhost:3000) in your browser.

4. **API Key Configuration:**  
   Click the "Settings" (gear icon) in the sidebar to enter your Gemini API Key. The key is stored securely in an `HttpOnly` cookie and is never exposed to the frontend or sent anywhere other than your local server.

## 🏗️ Architecture

The application is split into two secure environments:

1. **The Next.js Frontend/Backend (React 19):**  
   Manages the chat interface, session state, project history, and communication with the Gemini API.
2. **The Render Engine (React 18):**  
   Located in the `renderer/` folder. It is an isolated CLI sandbox powered by `@remotion/renderer` that executes the AI-generated code. This separation prevents dependency conflicts and insulates the Next.js app from the heavy headless browser instances needed for video rendering.
